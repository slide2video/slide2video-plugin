# Daniel Landi's agent plugins

| Plugin | What it does |
|---|---|
| [`batatais`](./batatais) | Reconstruct Batatais in Blender from maps and photographs with a scripted workflow. Supports Claude Code and Codex. |
| [`music-video`](./music-video) | Turns a theme into a finished music video: lyrics, a song from your own Suno account, word timings, and a code-rendered 2D/3D video. Start with its [README](./music-video/README.md). |
| [`lesson-videos`](./lesson-videos) | Turns a slide deck into narrated, animated study videos, one per chapter. Start with its [README](./lesson-videos/README.md). |

Install in Claude Code:

```
/plugin marketplace add DanielLandi/plugins
/plugin install lesson-videos@daniellandi
/plugin install music-video@daniellandi
```
